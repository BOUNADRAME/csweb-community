# Webhooks API

Les webhooks sont des points d'entrée PHP à la racine de CSWeb, appelés par vos
applications (plateforme, scripts, supervision, BI) **sans compte CSWeb** : un
jeton suffit. Ils servent à piloter et suivre le breakout, lire les journaux et
lire les médias.

<div className="nx-mt-4" />

> CSWeb **n'envoie pas** d'événements vers vos systèmes : ce sont vos
> applications qui appellent ces webhooks. Pour réagir à de nouvelles données,
> interrogez `breakout-status-webhook.php` à intervalle régulier ou planifiez le
> breakout dans CSWeb.

## Points d'entrée

| Webhook | Méthode | Rôle | Jeton | Référence |
|---|---|---|---|---|
| `/breakout-webhook.php` | POST | Déclencher le breakout d'un dictionnaire | `WEBHOOK_TOKEN_BREAKOUT` | [Breakout API](/reference/api/breakout#3-déclencher-à-la-demande) |
| `/breakout-status-webhook.php` | GET | État du breakout par dictionnaire | `WEBHOOK_TOKEN_STATUS` | [Breakout Status](/reference/api/breakout-status) |
| `/dictionary-schema-webhook.php` | GET, POST | Lire ou enregistrer la base cible d'un dictionnaire | `WEBHOOK_TOKEN_SCHEMA` | [Guide](/guides/admin/webhooks#configurer-la-cible-breakout-dun-dictionnaire) |
| `/log-reader-webhook.php` | GET | Lire les journaux de CSWeb | `WEBHOOK_TOKEN_LOGS` | [Guide](/guides/admin/webhooks#lister--lire-les-logs) |
| `/media-webhook.php` | POST | Lister et lire les médias (audio, photos) | `WEBHOOK_TOKEN_MEDIA` | [Guide](/guides/admin/webhooks#médias-audio-photos) |

## Règles communes

- **Authentification** : `Authorization: Bearer <jeton>`. Un jeton par webhook
  depuis 8.0.14 / 8.1.20 ; un jeton laissé vide reprend le jeton commun
  `BREAKOUT_WEBHOOK_TOKEN`, sauf pour les médias. Sans jeton configuré : `503`.
- **Réponse** :
  ```json
  { "success": true,  "data": { … }, "error": null, "meta": { … } }
  { "success": false, "data": null,  "error": { "code": "…", "message": "…" } }
  ```
- **Limite de débit** : 60 requêtes par minute et par appelant, réglable avec
  `WEBHOOK_RATE_LIMIT_PER_MIN` ; au-delà, `429` avec l'en-tête `Retry-After`.
- **Corps** : JSON, 64 Ko au plus. Toute action qui modifie quelque chose est en
  `POST`.
- **En-têtes** : `Cache-Control: no-store`, `X-Robots-Tag: noindex, nofollow`.
- **HTTPS obligatoire en production** : sinon le jeton circule en clair.

## Codes d'erreur

`missing_token`, `invalid_token`, `server_misconfigured`, `method_not_allowed`,
`body_too_large`, `rate_limited`, `invalid_body`, `invalid_dictionary`,
`invalid_filename`, `invalid_action`, `invalid_path`, `forbidden_path`,
`not_found`, `content_too_large`, `delete_disabled`, `dictionary_not_found`,
`file_not_found`, `file_not_readable`, `process_failed`, `breakout_failed`,
`internal_error`. Le tableau détaillé (code HTTP et cause) est dans le
[guide Webhooks](/guides/admin/webhooks#codes-derreur).
